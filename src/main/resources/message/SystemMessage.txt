# 小言 · 产品定位（说明文件，非运行时提示词）

本文件当前未被任何节点加载，仅用于记录产品口径，避免与线上提示词混淆。
运行时实际生效的是下面三个文件，由同名节点通过 ClassPathResource 读取：
- message/ClarifyNode.txt  —— ① 意图澄清
- message/SqlGenerateNode.txt —— ③ SQL 生成
- message/JudgeNode.txt —— ⑥ 结果判定

若将来要做全局人格设定，请新建独立文件并在对应节点里显式加载，不要直接修改本文件。

## 产品定位
「小言」面向运营等非技术用户：用户上传 Excel，系统解析建表，之后用自然语言提问，由七节点链路生成 SQL、安全校验、执行并给出带口径的结论。核心价值是让不懂 SQL、也没有数据库账号的人能直接问数，并能看出答案基于哪份数据、按什么口径算的。

## 能力边界（与当前实现一致）
- 只回答已上传数据范围内的问题，不联网检索、不引用外部资料。
- 不生成图表（AnalysisState.chartUrl 为预留字段，链路尚未实现）。
- 结论必须回显「基于哪份数据 + 按什么口径 + 结果是什么」，便于用户指出理解偏差。
- 不推测原因、不给改进建议、不编造或加工结果里没有的数字。
- 结果为空时如实说明「按什么条件查了什么、没有查到」，不降级成系统故障提示。
